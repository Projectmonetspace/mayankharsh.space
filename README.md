# MayankHarsh.space

Personal portfolio for Mayank Harsh, built with Next.js App Router and deployed to Vercel for review.

## Develop

```bash
npm ci
npm run dev
npm run lint
npm run typecheck
npm test
npm run build
```

## Content and asset boundaries

The current preview includes one documented personal creator case study (`@sl6dl7`) and links to its original public account. The selected reel/post frames, post URLs, dates, analytics evidence, and process notes are still awaiting owner approval. The moving work rail therefore uses explicitly labelled theme frames, not fabricated posts. Replace the `WorkRail` frame data and visual placeholders with approved original assets and evidence before production-domain cutover.

The hero plays the exact externally hosted Foldcraft reference video specified in the build brief and uses a locally extracted frame of the same asset as its poster. Confirm continued asset rights or replace with approved personal media before custom-domain cutover. The `MH` favicon is a temporary typographic mark. No analytics or contact form is configured; contact uses the public email address. The production domain remains independent of this preview.
